# 🎬 Meus Filmes Favoritos

Projeto desenvolvido para a disciplina de **Desenvolvimento Web** no curso de Sistemas de Informação.

---

## 📖 Sobre o projeto

Uma página web estática que apresenta minha seleção pessoal dos **3 filmes favoritos**, com layout moderno, responsivo e totalmente construído com **HTML5 e CSS3 puro** — sem PHP, sem JavaScript e sem frameworks externos.

Cada filme é apresentado em um card com:
- Capa oficial do filme
- Título, ano de lançamento, gênero e duração
- Sinopse
- Avaliação (nota IMDb)
- Elenco principal com nome e personagem

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica com `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- **CSS3** — estilização completa embutida na tag `<style>`, incluindo:
  - Variáveis CSS (`--custom-properties`)
  - Flexbox e CSS Grid para layout responsivo
  - Media queries para mobile
  - Efeitos visuais com gradientes e transições

## 🚀 Como visualizar

1. Clone o repositório:
```bash
git clone https://github.com/gianlucaanhezini/meus-filmes-favoritos.git
```
2. Abra o arquivo `index.html` no navegador — sem servidor necessário.

---

## 📱 Responsividade

O layout se adapta automaticamente:
- **Desktop** — cards com poster à esquerda e conteúdo à direita
- **Tablet / Mobile** — cards empilhados verticalmente
