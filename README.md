# 🎬 Meus Filmes Favoritos

Site em PHP que lista os 3 filmes favoritos com poster, descrição e elenco principal.

## Filmes

- ✨ **Harry Potter e a Pedra Filosofal** (2001)
- 🛡️ **Capitão América: O Primeiro Vingador** (2011)
- 🕷️ **Homem-Aranha: No Aranhaverso** (2018)

## Como rodar

```bash
php -S localhost:8000
```

Acesse: http://localhost:8000

## Features

- Dark/Light mode toggle
- Scroll reveal animations
- Totalmente responsivo (mobile-first)
- Poster, descrição, gênero, duração e elenco de cada filme
